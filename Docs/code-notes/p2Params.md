# p2Params.c / p2Params.h - notes

GENERATED by `tools/gen_params.py`: edit the generator and rerun it (then `./do-uncrustify`), never the
output. One spec gives the host's parameter table, the value names, and the panel's pages and sections, so
the three cannot disagree.

Every parameter is the instrument's own, as its display names it: the same ranges, and the same list entries
(the glyph prefixes the display draws in front of some shape names left out). Bipolar dials (detune, the
modulation amounts, the filter and amp modulation) store 0-127 and show −64..+63, as the instrument does.

## 1. Ids are forever
Projects save parameters by id, so the list is appended to and never reordered. Ids 0-10 are the first
plug-in's (two oscillators, volume, the filter); everything after is in page order as of 2026-10-17. Two
ranges changed before any release: the oscillator shapes grew from the three the engine plays to the
instrument's full lists.

## 2. Pages
Oscillators, Filter, Amp, Envelopes, LFOs, Mod, Arp and Global, as design §6 sets out. The plug-in's own
settings (oversampling, Anomalies) are on Global. Many parameters are not yet connected to the engine:
they are shown and saved now, and come alive as each part is built.
